ReservaMate — Mt. ClaRamuel Resort Reservation System
The problem

Mt. ClaRamuel Resort ran bookings through notebooks and phone calls. Staff logged reservations in spreadsheets, collected payment by cash or bank transfer, and reconciled everything by hand at day's end — a process that produced double-bookings, lost payment records, and a full-time admin burden.

What I built on the backend

Co-built with Edcel B. Yasay for my BS IT capstone (ISU Ilagan, December 2025). My focus was the server-side logic: a concurrency-safe booking engine, payment processing, and the data layer behind five core modules.

Booking engineRow-level locking prevents double-bookings under simultaneous requests
PaymentsMaya Business API, server-verified transactions
Access controlRole-gated endpoints for staff tiers (RBAC)
ReportingAggregated revenue queries by month, year, room type

Key backend decisions

MySQL handles writes with transaction-level safety so two guests booking the same room at the same moment can't both succeed. Maya Business was chosen because it supports Philippine e-wallets natively, which matter for the resort's local customer base. Security is layered: RBAC at the application layer, hashed credentials, SSL in transit, and encrypted storage at rest.

CIMC Patient Record Viewer
The problem

Hospital staff pulled patient records from physical folders stored across multiple rooms. Locating a single patient's history could take 15–30 minutes — a real problem in urgent care, and a full-time load on a dedicated records clerk.

What I built on the backend

A digital archiving and search system that migrated decades of physical records into a SQL Server database. Full-text indexing on name, patient ID, and admission date brings retrieval under 30 seconds. PDF rendering happens server-side, and role-based access restricts sensitive data to authorized staff only.

Key backend decisions

SQL Server was chosen to match the hospital's existing IT infrastructure. Full-text indexes on name and patient ID keep search fast as the dataset grows. PDFs are served through the backend rather than exposing raw file paths to the client — a deliberate constraint given the sensitivity of medical data.

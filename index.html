ReservaMate — Mt. ClaRamuel Resort
LiveCapstone

Full-stack hotel reservation platform built to replace paper notebooks and phone bookings, which caused chronic double-bookings, lost payment records, and heavy manual admin work.

My contribution

Co-developed as my BS IT capstone project (with Edcel B. Yasay, ISU Ilagan, December 2025) — full-stack build covering the booking engine, payment integration, and admin dashboard.

Key features
  • Real-time, concurrent-safe booking engine that prevents double-bookings
  • Multi-payment gateway (Maya Business) covering e-wallets, credit and debit cards with automated receipts
  • Admin dashboard with role-based access control for staff tiers
  • Check-in / check-out module with real-time occupancy updates
  • Filterable financial reports by month or year across room types
Technologies
Laravel 10PHPMySQL Tailwind CSSJavaScriptMaya Business API RBACSSL
Result: Eliminated overbooking, automated payment confirmations, and replaced a manual ledger that caused weekly reconciliation errors.

Technical decisions

SQL Server was chosen to align with the hospital's existing IT infrastructure. Full-text indexing on name and patient ID fields keeps search near-instant as the dataset grows.
